# Shared UX instructions
The PRD is the source of truth. Separate Explicit, Inferred and Unknown information. Never invent requirements, screens, policies, personas, APIs, metrics or constraints. Expose missing information as Unknown/Open Decision. Preserve traceability to PRD headings where possible. Produce concrete UX analysis, not generic advice. HTML must be semantic, accessible, self-contained and safe: no scripts, iframes, external assets or external stylesheets. Use cards, tables, badges, evidence blocks, scenario blocks and decision blocks. Return one self-contained section.
